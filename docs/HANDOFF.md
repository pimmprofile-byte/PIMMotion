# PIMMotion 인수인계 문서

> **한 줄**: 비개발자가 익숙한 툴(일러스트·프리미어) 사용감으로 게임을 **설계**하고, 그 결과를
> **코워크가 유니티로 빌드**, **팀이 유니티에서 QC**하는 파이프라인. 이 문서는 지금까지 만든 것과
> 이어서 할 것을 한 장에 정리한다.

---

## 1. 전체 워크플로우 (역할 분담)

```
① 레이아웃 뷰     씬 구성(박스 배치·정렬·클립·크롭·소리·이벤트 메모)      ← 사용자  (일러스트레이터식)
② 타임라인 뷰     블록(씬/인터랙션/영상) 순서 + 연속성 연장               ← 사용자  (프리미어식)
③ 에셋맵핑 뷰     쇼오더·오디오·인풋 레지스트리 (🚧 미구현)               ← 사용자  (config 정리)
        │  = 자동저장(project.pimm.json) + 인코딩(.pimmgame.json)
        ▼
④ 코워크          정리된 config·에셋을 해석해 유니티에 빌드               ← 코워크  (로컬 유니티)
        ▼
⑤ 유니티          재생하며 버그 잡기 (QC)                                ← 사용자/팀 (로컬 유니티)
```

- **이 툴(①②③)** = 설계·정리까지. **실제 유니티 빌드(④)** = 코워크. **구동·QC(⑤)** = 로컬 유니티.
- 클라우드 세션의 AI는 핌플레이어 **소스코드 작성/push**는 가능하나 **유니티 실행은 불가**(로컬 몫).

## 2. 지금까지 만든 것 (LIVE)

### 게임 에디터 — `tool/PIMM_UnityGameCreator.ver1.10.html` (단일 HTML, 설치 0)
| 영역 | 기능 |
|---|---|
| 하이어라키(좌) | 시퀀스그룹▸시퀀스▸씬▸박스, 유니티식 드래그·이름변경·우클릭 생성·접기, z-order(위=앞/배경 맨뒤) |
| 레이아웃 뷰 | 박스 배치·정렬, **파워포인트 스마트 가이드**(균등간격·여백 스냅), 원클릭 균등배치, **클리핑박스**·**자르기(크롭)**, **프레임유형(크롭/풀프레임)**, 레퍼런스 이미지 |
| 타임라인 뷰 | 프리미어식(게임뷰 상단+트랙 하단), **블록 시퀀스(씬/인터랙션/영상)**, **클립 연장=연속성**(하이어라키 자동복사+디졸브 없음), 성공/실패 텍스트 메모, **트랙 높이 조절**, 속성창 연동 |
| 재생(▶) | 전체화면 게임뷰(ESC 복귀). 레이아웃=가변이미지 500ms 스프라이트 / 타임라인=플레이헤드 스윕 |
| 이벤트 | 박스별 실행조건+명령(논코딩), 가변이미지박스 상태 |
| 저장 | **자동저장**(이미지=IndexedDB 오프로드로 용량 안 터짐) + **프로젝트 폴더**(위치 설정→자체완결 폴더) |
| 산출 | **인코딩(.pimmgame.json)** 자체완결 + 에셋 아카이빙 폴더 (핸드오프) |

- **허브** `tool/PIMMotion_Hub.ver0.2.html` — Forge/Track 진입점(게임에디터 LIVE, 나머지 🚧).
- 트윈 `tool/…`↔`UnityGameLayout.html` 바이트 동일 유지. 전 버전 tool/에 보존(ver1.0~1.10).

### 데스크톱 앱 준비 — `desktop/` + `.github/workflows/desktop-build.yml`
- Electron 스캐폴드(준비 완료). `pimm://` 보안 프로토콜로 서빙 → 프로젝트 폴더 기능 그대로 동작.
- `desktop-v*` 태그 push → GitHub Actions가 **.exe(윈도우)+.dmg(맥) 듀얼빌드**. 무서명 내부배포.
- **실제 패키징/로고/실행가이드 = 2.0 마스터링에서.** (`desktop/README.md`, `docs/electron-app-spec.md`)

## 3. 저장·공유 모델 (서버 없음)
- **구글드라이브 = 서버.** 프로젝트 폴더를 Drive 동기폴더에 두면 팀 자동 공유(깃 유사). 동시-같은파일 편집만 주의(파일분리+소프트잠금으로 우회). → `docs/collaboration-drive-sync.md`
- 자동저장: 무거운 이미지/오디오는 **IndexedDB**, localStorage는 경량 참조. 폴더 연결 시 폴더가 정본. → `docs/project-folder-spec.md`

## 4. 코워크가 빌드하는 법 (인코딩 → 핌플레이어)
- 입력: `.pimmgame.json`(자체완결) + 에셋 폴더. 결정론적 절차·스키마 → `docs/encoding-and-build.md`.
- 핌플레이어 repo: **`pimmprofile-byte/PIMM_unityPIMMplayer`**(세션에 add하면 임포터·런타임 로더 구현 가능).
- 리스킨(기존 메커니즘+config+에셋)이면 C# 0줄. 새 메커니즘만 코워크가 플래그하고 그 부분만 추가.
