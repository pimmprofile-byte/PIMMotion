# 핌코프 스킬·플러그인 통합 상태 (핸드오프)

> 포피스 스킬 3종을 핌코프 플러그인에 통합하고 구버전을 정리하기 위한 안내.
> ⚠️ `.plugin`은 Drive의 zip 산출물이라 이 레포 세션에서 직접 재패키징 불가 → **플러그인 빌드 공정에서 반영**해야 함.

## 1. 통합 대상 — 신 포피스 스킬 3종 (레포 `.claude/skills/`)
- `poffice-skill/` — 기록(대화→개인세션로그, 게이트·체크·미션 분류) + 역방향 export 반영
- `poffice-motherlog/` — 집계(개인세션로그→`poffice_board.json` 마더 config, 그린필드/포피스영역 저장). **원칙 2: 텍스트 무결성 / 원문 참조·아카이빙·무왜곡**
- `poffice-report-bot/` — 페르소나 브리핑(마더 config diff, 예약, "{이름} 포피스알림켜줘")
- 정본 스펙: `docs/poffice-board-spec.md`(A~H), 대시보드: `tool/PIMM_Poffice.ver0.2.html`

## 2. 핌코프 플러그인 (Drive)
- `pimm-cowork-plugin_v0.4.0.plugin` (최신) — **여기에 위 3종 통합**
- `pimm-plogic.plugin` — Plogic 계열
- 구버전 다수 존재(pimm-cowork-plugin.plugin 등) → 통합/정리 대상

### 해야 할 일 (플러그인 빌드 공정)
1. 위 3종 스킬을 `pimm-cowork-plugin` 다음 빌드에 포함.
2. **구버전 제거**: 플러그인 내 기존 "개인세션로그 스킬" / "포피스 스킬"(2스킬 모델)이 있으면 제거 — 신 3종으로 대체.
3. 배포 후 이전 `.plugin` zip들은 제로필드 정리(개인세션로그 정리 지시 참조).

## 3. 테마에이전트 스킬 — 보류 (대표 "그거 아닐거같다")
- 레포 `.claude/skills/`엔 독립 "테마에이전트" 스킬 없음. 테마 제작 로직은 **Plogic**(테마비트→노트→렌더→워크 T2 제작가이드 + 범용 크래프트 이론)에, Unity 빌드는 `pimm-unitygamecreator` 스킬에 존재.
- 대표가 병합 확신 못 함("그거 아닐거같다") + 주무시는 중 → **파괴적 병합/삭제 안 함(보수적 홀드).** 기능 누락 위험이 있으면 신설 대신 문서화만. 깨어나신 뒤 확정.

## 4. 현 세션에서 한 것 / 못 한 것
- ✅ 신 3종 스킬 저작·검수·커밋 (레포)
- ⛔ `.plugin` zip 재패키징 (도구·공정 밖) → 위 §2 지시로 핸드오프
- ⛔ Drive 구버전 삭제 (이동/삭제 도구 없음) → 제로필드 정리 지시로 핸드오프
