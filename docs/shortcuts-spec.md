# 단축키 시스템 스펙 (게임에디터)

> **사용자 결정**: 자주 쓰는 기능에 단축키. **Adobe 툴 기준**(이식난도↓) + **커스터마이징 가능**(템플릿 옆
> "단축키" 버튼 → 매핑 편집). **조합키 위주**(잘못 눌러 오작동 방지). 리스트 보고 배우게 정교하게.
> 자주 쓰는 건 위, 덜 쓰는 건 아래. 뷰이동 Alt+1~n, 재생 Alt+P, 이미지박스 Ctrl+I, 텍스트박스 Ctrl+T 등.

---

## 1. 시스템 구조
- **레지스트리** `SHORTCUTS`(기본맵) + `PROJECT.meta.keymap`(사용자 오버라이드, 폴더/localStorage 저장, 하위호환 추가만).
- 전역 `keydown` 핸들러가 조합을 정규화(`ctrl/alt/shift/meta + key`)해 매칭 → 액션 실행 + `preventDefault`.
  - **입력 포커스 가드**: input/textarea/contenteditable에 포커스면 편집 단축키(복사·전체선택 등)는 네이티브 우선(툴 단축키 무시).
  - **조합키 원칙**: 최소 1개 수정키(Ctrl/Alt/Cmd) 필수 → 단일 문자 오발동 방지. (삭제/ESC 등 관용 예외만 단독)
  - **Mac**: Ctrl→⌘ 매핑(⌘ 우선), Alt=⌥. 표기 OS별 자동.
- **단축키 편집 패널**: 상단 **템플릿 탭 옆 "⌨ 단축키" 버튼** → 모달. **그룹별 리스트(자주쓰는 것 위)**, 각 항목 클릭→새 조합 입력해 재매핑, 충돌 경고, 기본값 복원. 배우기용 전체 리스트 겸용.

## 3. 브라우저 vs 데스크톱 앱 (정직)
- **생성·잠금/숨김·보기 계열 = 전부 Alt 기반 → 브라우저에서도 동작**(사용자 요청 반영). Ctrl+숫자(탭전환)·Ctrl+±0(줌)·Ctrl+T/N/W(창/탭) 회피.
- 편집 관용키(복사 Ctrl+C·붙여넣기 Ctrl+V·실행취소 Ctrl+Z·저장 Ctrl+S 등)는 브라우저에서도 `preventDefault`로 동작.
- 남는 브라우저 선점키가 있으면 **데스크톱 앱(Electron)에서 완전 동작** + 편집 패널에서 안내(remap 가능).
- 리스트/툴팁·버튼 title에 조합 표기(배우기 쉽게). Mac은 Ctrl→⌘, Alt=⌥ 표기.

## 4. QA 수용 기준
- [ ] 기본 매핑 동작(뷰 Alt+1~n 이동, 재생 Alt+P, 생성 Ctrl+I 등), 입력 포커스 시 편집키 네이티브 우선
- [ ] 조합키만 발동(단독 문자 무시, 관용 예외만)
- [ ] 템플릿 옆 "⌨ 단축키" 패널: 그룹별(자주쓰는 것 위) 리스트, 재매핑·충돌경고·기본복원, 매핑 저장(폴더/LS)·리로드 유지
- [ ] Mac ⌘ 매핑, 브라우저 선점키 안내/대체 바인드
- [ ] 회귀: 기존 기능/저장/타임라인/클립/크롭/템플릿 무영향

## 5. 빌드 순서
- 로고(ver1.12) → 이미지박스 통합+템플릿(ver1.13) → **단축키 시스템(ver1.14)**. (단축키는 최종 기능셋+템플릿 탭을 참조하므로 템플릿 뒤. 편집 패널이 "템플릿 옆"에 위치.)
