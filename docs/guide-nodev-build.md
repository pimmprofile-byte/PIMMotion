# PIMMotion 게임에디터 — 무개발 사용자 가이드 (ver2.0 워크플로우)

> **목표**: 개발 지식이 전혀 없어도, 게임을 명확히 구상하고 그래픽 이미지만 준비하면
> 이 툴 하나로 게임을 **설계·정리(인코딩)**하고 → 코워크/핌플레이어(Unity)로 **빌드**할 수 있다.
> **대상**: 전문 디자인 툴을 써 본 적 없는 기획자/디자이너 (파워포인트 정도만 만져본 사람 기준).
>
> 이 가이드는 "열기 → 배치 → 이미지 정리 → 저장소에서 끌어오기 → 정확히 놓기 → 흐름 → 저장 → 내보내기"
> 순서로, **화면을 따라 클릭만 하면 되도록** 정리했습니다.

---

## 0. 이 툴은 익숙한 세 프로그램을 합친 것

| 하는 일 | 닮은 프로그램 |
|---|---|
| 화면에 이미지 **배치·정렬** (게임뷰 = 프로그램 모니터) | **일러스트레이터** |
| 게임 **진행 순서**(씬·인터랙션·영상)를 트랙으로 (하단 타임라인) | **프리미어 프로** |
| **상세 속성·기능 메모**(인스펙터)·**레이어**(하이어라키) | **유니티** |
| **이미지 정리**(배경제거·자르기) | 간단 **포토샵** |

**화면 구조**: 좌 = 레이어(하이어라키) / 중앙 = 게임뷰(캔버스) / 우 = 속성(인스펙터) / 하단 = 타임라인 / 상단 = 탭.
상단 탭 순서: **레이아웃 › 타임라인 › 에셋저장소 › 에셋에디터**.

> 어렵게 느껴지면 **레이아웃 탭 하나만** 써도 게임의 90%가 만들어집니다. 나머지 탭은 필요할 때만 열면 됩니다.

---

## 1. 핵심 낱말 3개만 먼저

- **시퀀스**(상단/좌측): 큰 단위(막). 코드명(SEQ#)은 자동·불변 — **표시 이름만** 바꿉니다.
- **씬**: 파워포인트 슬라이드 한 장 같은 화면. 한 시퀀스 안에 여러 개.
- **박스(요소)**: 씬 안에 올리는 배경·이미지·텍스트 한 덩어리.

---

## 2. 전체 흐름 (이 순서대로만 하면 됩니다)

```
① 열기        → 진행 중 프로젝트가 있으면 바로 에디터, 없으면 런처(홈)에서 새로 시작
② 배치        → 레이아웃 탭에서 박스를 올리고 정렬 (파워포인트처럼)
③ 이미지 정리 → 에셋에디터로 AI 이미지의 배경 제거·자르기 → 깨끗한 PNG 저장
④ 저장소       → 에셋저장소에서 정리된 이미지·템플릿을 씬으로 끌어다 놓기(드롭)
⑤ 정확 배치   → 프레임그래픽으로 이미지를 오차 없이 딱 맞게
⑥ 흐름        → 타임라인에서 씬·인터랙션·영상 순서와 "유지(연속성)"를 짠다
⑦ 저장        → 프로젝트 폴더에 자동 저장(이미지까지 안전하게)
⑧ 내보내기    → 인코딩 → 코워크/유니티가 빌드
```

당신은 ①~⑧을 툴 안에서 다 합니다. 유니티 빌드는 코워크(대화형 Claude)와 팀이 맡습니다(→ `guide-cowork-unity.md`).

---

## 3. 단계별 사용법

### ① 열기 — 진행 중이면 바로 편집, 아니면 런처

- 툴을 열면 **진행 중이던 프로젝트가 있으면 곧바로 에디터로** 들어갑니다(마지막 자동저장 또는 마지막에 연 폴더를 이어서).
- 진행 중인 게 없으면 **런처(홈 화면)**가 뜹니다 → **[새 프로젝트]**.
- 새 프로젝트 만들 때:
  1. 이름 입력
  2. **[위치 설정]** 클릭 → 파일탐색기가 열립니다 → 저장할 폴더 선택
  3. 그 자리에 **`<프로젝트명>/` 폴더**가 자동 생성됩니다(이미지·설정이 전부 이 한 폴더에 모임 = "자체완결 폴더").
- 저장 위치를 **구글드라이브 동기폴더**로 잡으면, 그 폴더가 팀에게 자동 공유됩니다(→ §7).

> 좌측 아래 **로고**를 누르면 허브로 이동합니다. "진행상황을 저장한 뒤 이동" 안내가 뜨니 저장 먼저 하세요.

### ② 배치 — 레이아웃 탭 (일러스트/파워포인트처럼)

박스 종류 (상단 툴바 또는 우클릭 생성):

- **배경 이미지**(Alt+B): 화면 전체(1920×1080) 배경. 자동으로 맨 아래·잠금.
- **이미지박스**(Alt+I): 그림 한 장. **"상태 추가"(Alt+S)**를 누르면 상태1·상태2…로 바뀌는 이미지가 됩니다(버튼 눌림/정답·오답/켜짐·꺼짐 등을 **박스 하나로** 표현). → 하이어라키가 깔끔해집니다.
  - *예전의 "가변이미지박스"는 없어졌습니다. 이제 이미지박스 하나 + 상태 추가로 통합되었습니다.*
- **텍스트박스**(Alt+T): 글자. `static`(고정) / `dynamic`(상황별 여러 글자 — "정답 시 → CLEAR!" 등).
- **클리핑박스**(Alt+K): 그 영역/모양(사각·둥근·타원)으로 아래 이미지를 **잘라 보이게** 하는 마스크 박스.

배치 팁:

- **정렬/분배**: 여러 박스 선택(Shift+클릭 또는 드래그) → 좌/중/우·상/중/하 정렬, 균등 분배.
- **스마트 가이드**: 드래그하면 파워포인트처럼 **점선 가이드**와 **간격 인디케이터**가 떠서 자동으로 맞아 붙습니다(스냅). **Alt를 누른 채 드래그**하면 스냅이 잠깐 풀려 미세조정.
- **정확한 숫자**: 인스펙터의 X/Y/W/H에 숫자를 직접 입력하면 딱 그 자리·크기로.
- **캔버스 이동/확대**: 마우스 휠 = 커서 기준 확대/축소, **스페이스바 누른 채 드래그 = 화면 이동**(손툴).
- 되돌리기 **Ctrl+Z**, 다시실행 **Ctrl+Shift+Z**.

### ③ 이미지 정리 — 에셋에디터 (배경 제거가 핵심)

AI로 만든 이미지(제미나이 등)는 대부분 배경이 지저분하거나 "가짜 투명"(격자무늬)입니다. **에셋에디터** 탭에서 정리합니다.

- 이미지 가져오기 → **자동 배경제거**:
  - **단색/평면 배경**: 네 모서리 색을 읽어 배경을 자동 제거. **허용치 슬라이더**로 얼마나 지울지 조절, 가장자리는 부드럽게(feather).
  - **격자(가짜 투명) 배경**: AI가 투명 대신 격자무늬를 진짜 픽셀로 그려준 경우 → 격자 패턴을 감지해 **진짜 투명**으로 바꿔줍니다.
- 그 밖에: **자르기 / 투명 여백 자동 트림 / 리사이즈 / 회전·반전 / 이미지 합치기 / 밝기·대비 조정**.
- 다 되면 **저장** → 깨끗한 투명 PNG가 **`assets/assetsEdited/`**에 들어가고, **에셋저장소에 자동으로 나타납니다**(원본은 그대로 보존).

> 마스크·브러시 같은 본격 편집은 아직 없습니다. "AI 이미지 배경 지우고 다듬기"에 특화되어 있습니다.

### ④ 저장소에서 끌어오기 — 에셋저장소

**에셋저장소** 탭은 자주 쓰는 것을 모아 둔 라이브러리입니다. 두 가지가 **자동으로** 보입니다:

1. **정리된 이미지**: 방금 에셋에디터에서 저장한 `assetsEdited/`의 PNG(썸네일 그리드).
2. **템플릿**: 미리 만들어 둔 **박스 묶음 컴포넌트**(결과창, 게이지바 등).

- **정리된 이미지를 씬으로 드롭** → 자동으로 **프레임그래픽 박스**로 배치됩니다(⑤ 참고).
- **템플릿을 씬으로 드롭** → 그 박스들이 씬에 **복사되어** 들어옵니다. 이후 자유롭게 편집(원본 템플릿과 연결 없음).

> 템플릿은 에셋저장소 안에서 직접 만들 수도 있습니다(레이아웃과 같은 도구, 단 박스만). 결과창처럼 반복되는 UI를 한 번 만들어 두면 계속 재사용.

### ⑤ 정확히 놓기 — 프레임그래픽 (오차 0)

게임 퀄리티는 **위치·크기 정확도**에서 갈립니다. 이미지를 딱 맞게 놓는 방법:

- 박스에서 **[프레임그래픽] 토글** → assetsEdited 이미지 적용(또는 저장소에서 드롭하면 자동).
- 적용하면 **박스 크기가 이미지 원본 크기로 바뀝니다**(박스 = 이미지). 그래서 이미지가 눌리거나 늘어나는 **드리프트(오차)가 0**입니다.
- 크기 조절: 사이즈 옆 **자물쇠(비율 락/언락)** — 락=비율 유지, 언락=자유 변형.
- 이동은 박스만 끌면 됩니다(다시 굽거나 외부 프로그램 불필요).

참고 — 이미지 만드는 3가지 방식(박스 속성의 **프레임유형**):

| 프레임유형 | 뜻 | 언제 |
|---|---|---|
| **프레임그래픽** | 박스=이미지, 오차 0 | **권장.** 오브젝트 하나하나 정확히 놓을 때 |
| 크롭프레임 | 이미지=박스 크기로 잘라 배치 | 간이 배치, 파일 작게 |
| 풀프레임 | 이미지=1920×1080 통짜 배경 | AI가 화면 전체를 한 장으로 만든 배경 |

### ⑥ 흐름 — 타임라인 (씬·인터랙션·영상 블록)

하단 **타임라인** 탭은 프리미어처럼 생겼습니다. 위 = 게임뷰, 아래 = 트랙.

- **메인 블록 레인**: **씬 블록 / 인터랙션 블록 / 영상 블록**을 **순서대로** 놓습니다.
  - 예: `씬1 › 인터랙션 › 씬2`, 또는 `씬1 › 인터랙션 › 영상 › 인터랙션 › 씬2`.
  - **인터랙션 블록** = 씬 사이의 진행 지점. 여기에 게임 진행방식 + **성공 시 / 실패 시 할 일**을 **글로 메모**합니다(분기 코드 아님, 사람이 읽는 지시문).
  - **영상 블록** = 게임이 아니라 영상이 재생되는 구간.
- **연속성(유지)**: 배경처럼 여러 씬에 계속 남아야 하는 박스는 **클립을 옆으로 길게 끌어(연장)** 둡니다. 그러면:
  - 그 씬들의 하이어라키에 박스가 **자동 복사**되고(손으로 다시 안 만들어도 됨),
  - 유니티에서 **깜빡임·BGM 재시작·디졸브 없이 그대로 유지**됩니다.
- **트랙 높이 조절**: 트랙 아래 경계를 드래그하면 트랙이 커져서 라벨·썸네일이 안 눌리고 보입니다.
- **소리**: BGM = 시퀀스 내내 지속, SFX = 인터랙션 순간 재생("정답 시 → correct.wav").
- 우측 속성창은 타임라인에서 **클릭한 대상**(클립/씬/인터랙션/영상)에 맞춰 바뀝니다.

### ⑦ 저장 — 프로젝트 폴더에 자동으로

- **자동저장**: 편집하면 프로젝트 폴더의 `project.pimm.json`에 자동 기록(**Ctrl+S**로 수동 저장도).
- **이미지·오디오는 파일로** `assets/` 폴더에 저장되고 설정은 경로만 참조 → **용량 걱정 없이** 무거운 이미지도 안전.
- 폴더를 아직 연결 안 한 경우엔 **IndexedDB**에 임시 저장되어 자동저장이 터지지 않습니다.
- "저장용량 초과" 경고가 뜨면 **[위치 설정]으로 폴더를 연결**하거나 내보내기로 백업하세요.

> **폴더 하나가 프로젝트 전부**입니다: 에디터 HTML 사본 + `project.pimm.json` + `assets/`(images/audio/reference/**assetsEdited**) + `encode/`. 이 폴더만 있으면 어디서든 이어서 작업하고, 팀에게 통째로 넘길 수 있습니다.

### ⑧ 내보내기 — 인코딩

- 툴바 **🎬 인코딩** → 시퀀스 선택 → **`encode/<SEQ#>.pimmgame.json`**(에셋·소리·좌표·씬·인터랙션·상태·전환이 전부 담긴 자체완결 파일).
- **내보내기 시** 최종 씬에 실제로 올라간 에셋만 **`assets/assetsIngame/`**로 정리(중복 제거) 복사됩니다 + 좌표 JSON → 코워크가 받으면 **똑같은 게임뷰**로 재현.
- **리스킨 사전점검 배지**: 기존 방식이면 "리스킨 호환"(초록), 새 방식이면 "신규 메커니즘 필요"(주황) — 주황이면 코워크와 상의.
- **폴더 README**: 폴더에 코워크용 안내(README)가 함께 정리되어, 받는 사람이 무엇을 어떻게 빌드할지 바로 압니다.

## 4. 단축키 치트시트 (조합키 위주 — 잘못 눌러도 안전)

> 모두 **수정키(Alt/Ctrl)와 함께** 눌러야 발동합니다. 생성·보기 계열은 브라우저와 안 겹치게 **Alt** 기반.
> 상단 **"⌨ 단축키" 버튼**에서 전체 목록 확인·재매핑 가능. (Mac은 Ctrl→⌘)

|---|---|---|---|---|
| Alt+1 | Alt+2 | Alt+3 | Alt+4~ | **Alt+P** (ESC 복귀) |

| 이미지박스 | 텍스트박스 | 배경 | 클리핑박스 | 상태 추가 | 씬 | 시퀀스 | 시퀀스그룹 | 템플릿 삽입 |
|---|---|---|---|---|---|---|---|---|
| Alt+I | Alt+T | Alt+B | Alt+K | Alt+S | Alt+N | Alt+Q | Alt+G | Alt+M |

## 5. 안전장치 & 자주 묻는 것

- **자동저장이 터져요("용량 초과")** → [위치 설정]으로 **폴더 연결**(이미지를 파일로 저장) 또는 내보내기로 백업.
- **글자가 흐릿해요** → AI 이미지에 글자를 넣지 말고 **텍스트박스**로 올리세요(수정·정렬 자유).
- **배경 지우기가 덜 됐어요** → 에셋에디터에서 **허용치 슬라이더**를 조금 올리고 다시.
- **이미지가 눌려 보여요** → **프레임그래픽**으로 적용하면 박스=이미지라 안 눌립니다.
- **박스가 안 움직여요** → 하이어라키에서 🔒 잠금 확인(배경은 기본 잠금, Alt+L로 토글).
- **씬 전환이 뚝뚝 끊겨요** → 그 박스의 클립을 타임라인에서 **길게 끌어(연장)** "유지"로.
- **새 게임 방식이래요** → 리스킨 범위를 넘음. 인코딩이 "신규 메커니즘 필요"로 뜨면 코워크와 함께.

## 6. 한 문장 요약

**진행 중이면 바로 편집 → 레이아웃에 배치 → 에셋에디터로 배경 지운 이미지를 → 에셋저장소에서 끌어와 → 프레임그래픽으로 정확히 놓고 → 타임라인으로 흐름·연속성 → 폴더에 자동저장 → 인코딩 → 코워크/유니티가 빌드.**
