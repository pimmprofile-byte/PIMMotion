## 0. 한 줄 정의
**경험 디자인 스튜디오.** 비주얼 아티스트·전략가·엔지니어로 구성된 국제 팀이 **예술·디자인·기술의 경계를 흐린다.** 디지털이 물리 공간과 만나는 지점에서 브랜드 경험을 만든다(파리·암스테르담, B Corp 인증). 클라이언트: Nike·Moncler·Lexus·Glossier·Jacquemus·Boucheron 등.
→ **우리와 정확히 같은 업(業)**: 이머시브·공간·브랜드 경험. 그래서 톤이 잘 맞음.

## 1. 홈페이지 디자인 언어 (핵심)

### 1-1. 히어로 = 작업물이 곧 히어로
- **풀블리드(edge-to-edge) 무빙 이미지/필름.** 배경을 "조각난·해석 불가한 이미지들의 연속"으로 깨뜨려 **호기심**을 유발(모핑 그래픽). 카피가 아니라 **작업 영상 자체가 첫인상**.
- 브랜드 소개 문구를 앞세우지 않음 → "우리가 무엇을 만드는지"를 **보여주는** 방식. (Work-first, tell-less)
- 시사점: 우리 히어로도 `assets/hero.mp4`(스케치필름) 훅이 이미 있음. **정지 회색 그라디언트 → 실제 무빙 필름**으로 채우는 게 랜덤스튜디오 결의 핵심.

### 1-2. 캔버스 / 팔레트
- **모노톤·미니멀 베이스**(거의 무채색/다크) → 작업물의 색이 튀도록 배경은 물러섬. UI 크롬 최소화.
- 시사점: 우리의 다크 그린(#0d… + #00FF99 액센트)은 이미 이 원리를 따름. **액센트는 절제**하고 미디어에 색을 양보.

### 1-3. 타이포그래피
- **크고 볼드한 대형 타이포**. 화면을 압도하는 스케일.
- ⚠️ **그러나 평론의 지적**: 오버사이즈 볼드가 **기술적/설명 텍스트의 가독성을 떨어뜨림**. 큰 타입은 '한 문장 선언'에만 쓰고, 본문 설명까지 키우면 읽기 힘들어짐.
- 시사점: 히어로 H1은 크게(우리 "몰입을 짓는 / 공간 회사" 잘 됨). **단, 본문·설명은 절대 같이 키우지 말 것** — 랜덤스튜디오가 실수한 지점.

### 1-4. 모션 / 인터랙션 (Awwwards SOTD 급)
- **부드러운 모멘텀 스크롤**, 스크롤 연동 리빌·패럴랙스.
- **호버 시 프로젝트 썸네일이 영상으로 재생/스크럽**되는 미디어-포워드 인덱스.
- 커서/포인터 반응, 요소 모핑 등 "살아있는" 마이크로 인터랙션. **기술력을 UI로 증명**(엔지니어 팀 보유의 시그니처).
- 시사점: 우리는 이미 IntersectionObserver 리빌·히어로 sweep·모달 보유. **다음 레벨 = 프로젝트 카드 호버 시 대표 영상/이미지 미세 확대·재생**(우리 `.card-hero-img{transform:scale(1.05)}` 이미 씨앗 있음).

### 1-5. 프로젝트(케이스) 프레젠테이션
- **풀스크린 몰입형 미디어**로 각 프로젝트를 보여줌. 텍스트는 최소, 결과물 비주얼이 압도.
- 프로젝트 예: Jacquemus 공간+인터랙티브 시노그래피, Boucheron 도쿄 플래그십 리빙 파사드, Nike 퐁피두 브랜드 전시, 다수 리테일 설치·팝업.
- 시사점: 우리 ARTWORKS 모달을 **더 미디어 중심**으로(대형 히어로 이미지·갤러리·짧은 크레딧). 설명은 짧게.

### 1-6. 사이트 구조 / 내비게이션
- 페이지: **Projects · About(영상) · Sustainability · Careers/Contact** — 극도로 단순.
- ⚠️ **평론의 지적**: 현재 위치 표시가 불명확, 내비 기능을 찾기 어려움, **푸터 부재**로 이동이 불편. → 미니멀을 밀어붙이다 **길찾기(way-finding)를 희생**.
- 시사점: 미니멀은 따르되 **명확한 내비 상태 표시 + 제대로 된 푸터**는 유지(우리 홈페이지엔 이미 푸터·섹션 앵커 내비 있음 → 랜덤스튜디오보다 이 점은 우리가 낫다. 유지할 것).

### 1-7. 카피 톤
- 선언적·절제. 설명 나열이 아니라 **강한 한 문장 + 작업으로 증명**. 브랜드 자화자찬 최소.

## 2. "왜 통하는가" — 차용할 원칙 5
1. **Work-first**: 말보다 작업 영상이 먼저 말하게 한다.
2. **캔버스는 물러서고 미디어가 색을 갖는다**(무채/다크 베이스 + 절제된 액센트).
3. **선언형 대형 타이포 1문장** + 나머지는 조용히.
4. **살아있는 마이크로 인터랙션으로 기술력을 증명**(호버 재생·모멘텀·모핑).
5. **몰입형 풀스크린 케이스**(텍스트 최소, 비주얼 최대).

## 3. "따라 하지 말 것" — 랜덤스튜디오의 약점 3
1. **본문까지 오버사이즈 볼드 → 가독성 저하.** (설명 텍스트는 읽기 좋은 크기 유지)
2. **길찾기 희생**(현재 위치 불명·내비 난해·**푸터 없음**). → 우리는 명확한 앵커 내비 + 푸터 유지.
3. **과한 실험성으로 "무엇을 하는 회사인지" 즉시 안 읽힘.** → 우리는 히어로 서브카피로 업(業)을 1초 안에 전달(현행 "브랜드 팝업·체험 전시·방탈출…" 유지).

## 5. 결론 (핌 관점)
랜덤스튜디오는 **"작업물이 말하게 하고, 캔버스는 물러서며, 인터랙션으로 기술을 증명"**하는 스튜디오 포트폴리오의 정석. 우리 홈페이지는 **구조·카피·내비·푸터가 이미 그들보다 정돈**돼 있음(그들의 약점을 안 밟음). 남은 격차는 오직 **실제 무빙 미디어와 호버 인터랙션의 밀도** — 즉 "코드"가 아니라 "실사 필름·사진 + 호버 재생" 채우기.
→ **다음 작업 1순위: 히어로 스케치필름 + 프로젝트 실사 이미지 연결, 호버 재생 강화.** (실물 에셋은 대표 제공 필요.)
