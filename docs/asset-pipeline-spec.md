# 에셋 파이프라인 — 에셋에디터 · 에셋저장소 · 프레임그래픽 (게임에디터)

> **동기(사용자)**: 게임에서 위치·크기 정확도가 게임 퀄리티를 좌우. 과거엔 일러스트 1920×1080 대지에
> 오브젝트를 배치해 **투명 풀프레임 PNG 30개+**로 내보냈으나(정확하지만 Adobe 종속·수정 지옥),
> 이 툴로 **박스+좌표**로 대체. 남은 문제 = 크롭프레임 드리프트(이미지≠박스 크기)와 AI 이미지 정리 필요.
> 해결 = **프레임그래픽(드리프트 0) + 에셋에디터(AI 이미지 정리·자동 배경제거) + 에셋저장소(빠른 접근)**.

---

## 1. 탭 구성 (템플릿 탭 → 에셋저장소로 대체)
```
레이아웃 › 타임라인 › [에셋저장소] › [에셋에디터]
```
- 기존 "템플릿" 탭은 **에셋저장소**로 흡수/대체.

## 2. 에셋에디터 (이미지 편집)
> AI 이미지(제미나이 등) 정리 특화. 마스크/브러시 등 본격 래스터 편집은 **제외**(현 단계).
- 이미지 가져오기 → 편집:
  - **자동 배경제거(필수)** — 두 케이스 모두:
    1. **단색/평면 배경**: 4모서리 색 샘플 → 연결된 배경 flood-fill 제거 + **허용치 슬라이더** + 가장자리 feather.
    2. **격자(가짜 투명) 배경**: AI가 투명 대신 **격자무늬를 실제 픽셀로** 준 경우(제미나이) — 밝은 두 색(흰+연회색)의
       규칙적 그리드를 모서리에서 패턴 감지 → 두 색을 허용치로 제거 → **진짜 투명(alpha)으로** 변환. (edge-connected 우선.)
    단색·격자 배경에 잘 먹음. *복잡 배경 완전분리(ML)는 2.0 데스크톱 앱 모델 번들로 추후.*
  - **크롭 / 투명 여백 트림(자동) / 리사이즈 / 회전·반전**
  - **이미지 합치기(레이어)** — 오브젝트 조합
  - 기본 조정(불투명도, 밝기/대비 정도)
  - 캔버스 크기 지정(투명 배경)
- **저장 → `assets/assetsEdited/`에 새 PNG(투명)**로. 원본 비파괴. → **에셋저장소에 자동 등장**.

## 3. 에셋저장소 (Asset Repository) — 빠른 접근 라이브러리
- **자동 표시** 두 종류:
  1. **에디트 완료 파일** — `assets/assetsEdited/`의 PNG(썸네일 그리드).
  2. **준비된 템플릿** — 박스 컴포넌트(결과창·게이지바 등, `PROJECT.templates[]`).
- 여기서 레이아웃/씬으로 **드롭**: 에디티드 이미지 → 프레임그래픽 박스로 배치, 템플릿 → 박스 묶음 복사 삽입.
- 폴더 config로 저장(ver1.11 폴더 저장 위에), assetsEdited는 파일·상대경로 참조.

## 4. 프레임그래픽 (레이아웃 박스 모드) — 드리프트 0
- 박스에서 **[프레임그래픽] 토글** → 파일탐색기(또는 에셋저장소) → assetsEdited 이미지 적용.
- 적용 시 **기존 박스크기 폐기, 이미지 원본 크기로 박스 재생성**(박스=이미지). `object-fit: fill`(레터박스 드리프트 없음).
- **비율 락/언락**(일러스트식 자물쇠, 사이즈 옆): 락=비율유지, 언락=자유변형. 프레임 안 이미지 오프셋/스케일 미세조정(선택).
- 결과: **크롭프레임의 드리프트 제거 = 풀프레임 정확도**, 이동은 박스만(재베이크·Adobe 불필요).
- frameType 3모드: `크롭프레임`(간이) / `풀프레임`(AI 통짜 배경) / **`프레임그래픽`(정확·오브젝트 권장)**.

## 5. 폴더 구조 (assetsEdited / assetsIngame)
```
<프로젝트>/assets/
  images/        # 임포트 원본
  audio/ ...
  reference/
  assetsEdited/  # 에셋에디터 저장본(편집 완료 PNG) — 에셋저장소가 여기서 자동 표시
  assetsIngame/  # 내보내기 시, 최종 씬에 실제 올라간 에셋만 dedup 복사(핸드오프 정리)
```
- **내보내기**: 최종 씬에 배치된 에셋만 `assetsIngame/`로 중복저장(정리본) + 좌표 JSON → **동일 게임뷰 재현**.

## 6. 이미지 임베드 SVG + 합성 렌더 (검증)
- **이미지 임베드 SVG**: 실제 이미지를 좌표에 `<image>`로 임베드 → 일러스트에서 **진짜 레이아웃** 확인(1회 검증 후 Adobe-free).
- **1920×1080 합성 렌더**: 씬 전체를 PNG 한 장으로 flatten 내보내기 → 툴 내에서 풀프레임 정확도 검증.

## 7. 워크플로우 (사용자 확정)
```
① 에셋에디터: 이미지 가져와 배경제거·정리 → 저장 → assets/assetsEdited/
② 에셋저장소: 에디티드 파일 + 템플릿 자동 표시 → 빠르게 접근
③ 레이아웃: 박스 [프레임그래픽] → assetsEdited 적용 → 박스=이미지 → 비율락 리사이즈 + 위치조정
④ 내보내기: assetsIngame(dedup) + 좌표 JSON (+임베드 SVG/합성 렌더) → 동일 게임뷰
```

## 8. QA 수용 기준
- [ ] 에셋에디터: 자동 배경제거(허용치·feather), 크롭/트림/리사이즈/회전/합치기/기본조정, 투명 PNG 저장 → assetsEdited
- [ ] 에셋저장소: assetsEdited + 템플릿 자동 표시, 씬 드롭
- [ ] 프레임그래픽: 토글→이미지 적용 시 박스=이미지 크기, fill(드리프트 0), 비율 락/언락, 이동/리사이즈
- [ ] 폴더: assetsEdited 저장, 내보내기 시 assetsIngame dedup 복사 + 좌표 JSON, 동일 게임뷰 재현
- [ ] 임베드 SVG(실제 이미지)·합성 렌더 검증
- [ ] 하위호환(추가만), 회귀 없음
