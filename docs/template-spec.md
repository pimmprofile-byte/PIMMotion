# 템플릿 시스템 + 이미지박스 통합 (게임에디터 — A안)

> **사용자 결정**: ① 일반/가변 이미지박스를 **"이미지박스" 하나로 통합**(상태 추가하면 전환).
> ② 재사용은 **"템플릿"** 으로 — 결과창·게이지바 등 **박스로 된 컴포넌트**를 미리 만들어 두고 필요할 때 씬에 가져다 씀.
> ③ 상단 탭 **레이아웃 › 타임라인 › 템플릿** 순서. ④ 템플릿 에디터 = 레이아웃과 같은 뷰지만 **박스만**(시퀀스그룹/씬 계층 없음).

---

## 1. 이미지박스 통합 (A안)

- **이미지박스 하나**만 존재. 기본 = 그림 한 장(정적). **"상태 추가"** 누르면 상태1~n으로 전환되는 이미지가 됨(기존 가변 기능).
- 생성 메뉴에서 **"가변이미지박스" 항목 제거** → 이미지박스 + (상태 추가).
- **마이그레이션(하위호환)**: 기존 `kind:"prefab"`(가변)·상태 있는 이미지박스 → 통합 이미지박스로 로드(데이터 유실 없음). 기존 states[]/previewSrc 그대로 소비.
- 인코딩/Unity: 상태 0~1개=단일 스프라이트, 2개 이상=상태 교체(setState). 스키마 불변(추가만).
- "재사용/공유"는 박스 토글이 아니라 **템플릿**(아래)으로 해결 → 개념 단순화.

## 2. 템플릿 = 재사용 컴포넌트 (박스 묶음)

- **템플릿** = 이름 붙은 **박스들의 묶음**(이미지·텍스트·상태 이미지 등). 예: 결과창(배경+텍스트+버튼), 게이지바(바탕+채움).
- **미리 만들어 라이브러리에 저장** → 필요할 때 씬에 **가져와 사용**.
- 데이터: `PROJECT.templates[] = { id, name, w, h, boxes:[...] }` (박스 스키마는 레이아웃 박스와 동일 재사용). 자동저장·핸드오프 포함(추가만, 하위호환).
- **폴더 config 저장(사용자 요청)**: 프로젝트 폴더 연결 시 템플릿도 **폴더의 config로 저장** — `project.pimm.json`에 `templates[]` 포함 + (선택) `templates/` 폴더에 개별 `<template>.json`으로도 내보내 **프로젝트 간 재사용/공유** 용이. 템플릿이 쓰는 이미지 에셋은 `assets/`에 파일로(상대경로 참조), IndexedDB 경량저장 원칙 준수.

## 3. 템플릿 탭 & 에디터

> **개정(사용자)**: 별도 "템플릿" 탭 대신 **에셋저장소** 탭으로 흡수 — 에셋저장소가 에디트 완료 파일
> (assetsEdited) + 템플릿을 **자동으로 함께** 표시(빠른 접근). 상세 = `docs/asset-pipeline-spec.md`.
> 아래 템플릿 에디터/CRUD는 에셋저장소 내에서 제공.

- ~~상단 탭 "템플릿"~~ → **에셋저장소** = 레이아웃 › 타임라인 › **에셋저장소** › 에셋에디터.
- 에디터 = **레이아웃과 동일한 캔버스·편집 도구**(배치·정렬·스마트가이드·클립·크롭·상태·z순서) 재사용.
- **단, 박스만** — 시퀀스그룹/씬 계층 **없음**. 좌측은 "템플릿 목록 + 선택 템플릿의 박스 트리"(플랫).
  - 새 템플릿 만들기 / 이름변경 / 복제 / 삭제. 캔버스 크기는 템플릿별(결과창은 작게 등) 또는 1920×1080 기준 배치.
- 재생/타임라인 같은 씬·진행 개념은 템플릿에 없음(정적 컴포넌트).

## 4. 씬에 템플릿 넣기 (삽입)

> ⑤ 삽입 방식 = **복사 삽입 확정(사용자 결정).** 연동(프리팹식) 없음.
- 레이아웃/씬에서 **"템플릿 삽입"** → 라이브러리에서 골라 현재 씬에 배치.
- **복사 삽입**: 템플릿 박스들이 그 씬에 **그냥 복사(박스 추가)** 되어 들어옴 → 이후 그 씬에서 **원하는대로 박스 교체·편집** 자유. 원본 템플릿과 연결 없음(단순).
- 삽입된 박스들은 그룹으로 함께 이동/정렬되면 편함(선택).

## 5. 핸드오프 / Unity

- `templates[]`(정의) + 씬 박스에 템플릿 출처 표식(복사면 메모, 연동이면 `templateRef`). 코워크가 컴포넌트로 인식.
- 게이지바 등은 상태/값 매핑을 이벤트·메모로(논코딩). 결과창은 텍스트 동적치환 등 기존 이벤트 활용.

## 6. QA 수용 기준

- [ ] 생성 메뉴에 "가변이미지박스" 없음, 이미지박스 하나 + "상태 추가"로 전환 이미지 됨
- [ ] 기존 프로젝트(가변/프리팹·상태 이미지) 로드 시 통합 이미지박스로 무손실 마이그레이션
- [ ] 상단 탭 순서 레이아웃 › 타임라인 › 템플릿, 템플릿 탭 진입
- [ ] 템플릿 에디터 = 레이아웃 편집 도구 재사용, **박스만**(시퀀스/씬 계층 없음), 템플릿 CRUD
- [ ] 템플릿 라이브러리에서 씬으로 삽입(복사) → 박스들이 씬에 들어오고 편집 가능
- [ ] 자동저장/핸드오프에 templates[] 포함, 하위호환
- [ ] 초심자: "이미지박스(+상태)" 하나 + "필요하면 템플릿 가져오기"로 개념 단순
