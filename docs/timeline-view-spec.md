# 타임라인 뷰 스펙 (게임에디터 — 블록 시퀀스 + 연속성 연장)

> **핵심(개정)**: 타임라인 = **프리미어프로형**. 게임뷰(프로그램 모니터)는 **상단**, 타임라인은 **하단**.
> 두 축으로 구성:
> ① **메인 블록 레인** — 씬/인터랙션/영상 **블록을 순서대로** 배치(씬1 › 인터랙션 › 씬2 …).
> ② **요소 트랙** — 각 씬의 박스가 클립으로. **클립을 길게 끌면(연장)** 여러 씬에 걸쳐 **유지(연속성)**.
> 성공/실패는 분기 그래프가 아니라 **인터랙션 블록의 텍스트 메모**.
> (원래 `tool-concept.md` §2 트랙/클립/연속성과 정합. ver1.5 분기 그래프·ver1.6 "인터랙션=축" 모두 교정.)

---

## 0. 전체 워크플로우 (역할 분담 — 사용자 확정)

```
① 레이아웃 뷰   씬을 구성한다 (박스 배치·정렬·소리·이벤트 메모)        ← 사용자 (일러스트레이터식)
② 타임라인 뷰   블록(씬/인터랙션/영상)을 순서 배치 + 연속성 연장        ← 사용자 (프리미어식)
        │  = 인코딩/핸드오프(config)로 정리
        ▼
③ 코워크        정리된 내용을 확인·해석해 유니티에 빌드                ← 코워크 (로컬 유니티 접근)
        ▼
④ 유니티        재생하며 버그를 잡는다 (QC)                          ← 사용자/팀원 (로컬 유니티)
```

---

## 1. 레이아웃 (프리미어프로형)

```
┌───────────────────────────────────────────────────────┐
│  ▶재생    [ 프로그램 모니터 = 게임뷰 (플레이헤드 지점) ]      │  상단
├──────────────┬────────────────────────────────────────┤
│ 저장소(Repo)  │  메인 블록 레인:                            │
│  · 씬박스     │   [ 씬1 ][인터랙션][ 씬2 ][인터랙션][ 영상 ]   │  ← 블록 순서
│  · 인터랙션   │  ─────────────────────────────────────    │
│  · 영상       │  요소 트랙(씬 박스들, 클립 연장 가능):          │
│              │   🎬배경  [████ 배경A (씬1~씬2 유지·persist) ███]│  ← 길게 끌면 연장
│              │   🅄UI    [PressKey]      [버튼들]            │
│              │   🅣텍스트 ["PRESS ANY KEY"]                  │
│              │   🔊오디오 [████ BGM 유지 ████]               │
└──────────────┴────────────────────────────────────────┘
```

- **게임뷰 상단 + 타임라인 하단**. 플레이헤드(블록/지점) → 상단 모니터가 그 순간 화면.

## 2. 저장소 (Repo)
- 레이아웃의 **씬**이 씬박스로 자동 파싱. + **인터랙션 블록**·**영상 블록** 생성용 항목.
- Repo → 메인 레인으로 드래그해서 블록 배치.

## 3. 메인 블록 레인 = 씬 / 인터랙션 / 영상 (사용자 교정 핵심)

> **인터랙션은 가로축 그 자체가 아니라 "블록"이다.** 씬 사이에 인터랙션 블록을 놓는다.

| 블록 | 의미 | 필드 |
|---|---|---|
| **씬 블록** | 하나의 씬(그 씬의 박스들이 요소 트랙에 깔림) | sceneId, 지속 구간 |
| **인터랙션 블록** | 씬 사이 진행 지점 | 게임 진행방식 + **성공 시 실행작업(텍스트)** + **실패 시 실행작업(텍스트)**. 분기 라우팅·선택팝업 없음 |
| **영상 블록** | 영상이 재생되는 구간(게임 아닌 콘텐츠) | videoAssetId, 길이/자동진행, 메모 |

- 구성 예: **씬1 › 인터랙션 › 씬2**, 또는 **씬1 › 인터랙션 › 영상 › 인터랙션 › 씬2**.
- 블록은 드래그로 순서 변경·삽입·삭제.
- **블록 라벨 = 그 블록의 이름**: 씬 블록은 **씬 이름(씬1, 씬2…)**, 인터랙션 블록은 인터랙션 이름, 영상 블록은 영상 이름.
  (현재 상단이 "인터랙션"으로 고정돼 있는데 → **씬 블록엔 씬 이름이 뜨도록** 교정. 축이 아니라 블록별 이름.)

## 4. 요소 트랙 + 클립 연장 = 연속성 (사용자 교정 핵심)

- **씬 블록을 놓으면** 그 씬의 박스가 role별 요소 트랙(배경/UI/텍스트/오디오)에 **클립**으로 깔린다.
- **프리미어처럼 클립을 가로로 길게 끌면(연장)** → 그 박스가 **인접 씬 블록까지 걸쳐 유지**됨을 표기.
  이때 **자동으로**:
  1. **하이어라키 복사 추가**: 연장된 씬들의 하이어라키에 그 박스(예: 배경이미지)가 **자동 복사·추가**된다.
     (같은 배경을 씬2에도 두는 것을 손으로 다시 안 만들어도 됨)
  2. **논코딩 연속성 표식(디졸브 방지)**: 길게 끌어진 에셋박스는 `continuity:"persist"` + **공유 `crossSceneId`**로
     표시 → 유니티 빌드 시 **오브젝트를 파괴/재생성하지 않고 그대로 유지**(깜빡임·재시작·디졸브 없음).
     **코드 분기가 아니라 표식(논코딩)** — 코워크가 이 표식을 읽어 오브젝트 재사용으로 구현.
- 연장 해제(클립을 다시 줄이면) → 그 씬에서의 복사본/persist 표식 해제(원상).
- 클립 경계에 트랜지션(컷/페이드/디졸브) 부착 가능(단, persist 구간 내부는 유지가 기본).

## 5. 재생(▶) — 뷰별 (기존 유지)
- 레이아웃 뷰 = 디자인/그리드 프리뷰, 가변이미지박스 500ms 스프라이트.
- 타임라인 뷰 = **플레이헤드 스윕**: 메인 레인 블록을 순서대로 훑으며 전체화면 게임뷰(상단 모니터)가 각 구성으로 전환.
  인터랙션 블록의 성공/실패 메모는 주석 표시, 영상 블록은 영상 표시(또는 플레이스홀더). 분기 선택·팝업 없음. ESC 복귀·폴백 유지.

## 6. 내보내기(핸드오프)
- **블록 시퀀스** = `blocks[]`(순서): `{type:"scene|interaction|video", ...}`
  - scene: sceneId + 트랙/클립 구간
  - interaction: `{gameMethod, successMemo, failMemo, transition}`
  - video: `{videoAssetId, duration, autoAdvance, memo}`
- **연속성** = 각 박스 `continuity:"persist|change|enter|exit"` + `crossSceneId`(persist 공유키) + `span`(걸친 씬/블록 범위). Unity가 재사용(디졸브 없음).
- 코워크가 이 config를 읽어 진행/연속성/영상 구성. 성공/실패 메모는 사람이 읽는 지시문(자동 분기코드 아님).

## 7. QA 수용 기준
- [ ] 게임뷰 상단 + 타임라인 하단(프리미어형)
- [ ] 메인 레인에 **씬/인터랙션/영상 블록**을 순서대로 배치·재정렬 (씬1›인터랙션›씬2, 씬1›인터랙션›영상›인터랙션›씬2)
- [ ] 인터랙션이 **블록**으로 존재(축이 아님), 성공/실패 **텍스트 메모** 저장
- [ ] 영상 블록 배치·에셋 참조·핸드오프 포함
- [ ] 씬 블록 놓으면 그 씬 박스가 요소 트랙에 클립으로
- [ ] **클립을 길게 끌면(연장)** → 연장된 씬 **하이어라키에 박스 자동 복사** + `continuity:persist`+공유 `crossSceneId` 표식
- [ ] 연장 구간이 **디졸브/재생성 없이 유지**로 config에 표기(논코딩), 연장 해제시 원상
- [ ] 플레이헤드 이동 → 상단 모니터 갱신, 재생 스윕(전체화면·ESC)
- [ ] 내보낸 config에 blocks[](씬/인터랙션/영상) + 연속성(persist/crossSceneId) 포함

> 목표: **씬·인터랙션·영상을 블록으로 순서 짜고, 배경 등은 클립 연장으로 여러 씬에 걸쳐 "유지"**시킨다.
> 유지된 에셋은 디졸브 없이 그대로(논코딩 연속성). 분기 그래프 같은 무거운 로직은 없다.

## 7.5. 우측 속성창 = 타임라인 선택에 연동 (버그 교정)

> **현재 버그**: 타임라인 뷰의 우측 속성창이 **레이아웃/하이어라키용 인스펙터를 공유**해서,
> 타임라인의 클립/블록을 클릭해도 그 박스를 가리키지 않음(SEL이 하이어라키 선택에만 묶임).

- 타임라인 뷰에서 **선택 대상별로 우측 속성창이 바뀌어야** 함:
  - **클립(박스) 선택** → 그 박스 속성 + **타임라인 관련 속성**(연속성 persist/change, span 걸친 씬 범위, assetMode(박스핏/풀프레임), 트랜지션).
  - **씬 블록 선택** → 씬 이름·구간·포함 박스 요약.
  - **인터랙션 블록 선택** → 게임 진행방식 + 성공/실패 메모.
  - **영상 블록 선택** → 영상 에셋·길이·자동진행.
- 타임라인 선택 상태를 별도로 관리(`tlSel`)하고, `renderInspector`가 `activeTab==="timelineview"`일 때 그 선택을 반영.

## 8. 기존 요소와의 관계
- 기존 하단 "🎞 연속성 트랙"은 이 뷰의 요소 트랙 + 클립 연장으로 **흡수**(중복 제거).
- 씬(시퀀스>씬>박스)·이벤트(박스 내부 동작)·상태(가변이미지박스)와 정합: 타임라인 = **블록 순서 + 연속성(상위 흐름)**.
- 이전 데이터(ver1.5 timelineFlow, ver1.6 timeline.blocks 단순형)는 로드시 무시/이관, 크래시 없이 하위호환.
