# 포피스 체계 — 팀원별 사용 시나리오 (검수용)

> 목적: 각 팀원이 포피스 체계를 **실제로 어떻게 쓰고, 무슨 일이 일어나고, 어떤 효과**가 있는지 정리.
> 검수에이전트가 이 문서를 기준으로 실제 동작을 확인한다. 정본 스키마: `docs/poffice-board-spec.md`(A~H).

## 0. 공통 사용 흐름 (누구나 동일)
1. **일한다 = 기록된다** — 코워크/코드와 대화로 업무 진행 → `Poffice-Skill`이 그 대화를 **개인세션로그**로 자동 기록(게이트·체크·미션 분류). 저장: **블루필드 `[2.블루필드:아카이브].PIMM_archive` > 개인DB > {이름} > Session_세션로그**. ("서류를 쓰는 게 아니라 대화가 서류가 된다.")
2. **집계된다** — 주기적으로 `Poffice-MotherLog`가 개인세션로그를 요약·분석 → 대시보드용 `poffice_board.json`(마더 config) 생성. 저장: **그린필드 `[1.그린필드:프레임워크].PIMM_framework` > `[2.포피스_섹터].Poffice`**.
3. **본다** — 포피스 대시보드(`tool/PIMM_Poffice.ver0.2.html`) 실행 → **본인 이름 선택** → 본인 워크스페이스만(미션 마일스톤 / 권한 게이트 / 체크리스트 / 세션로그). 타인 것 비노출.
4. **체크·메모한다** — 투두 체크(3상태) + 미션/세션 메모 → **내보내기** → `poffice_export_{이름}.json` → `Poffice-Skill`이 세션로그에 반영(역방향, 체크·메모만).
5. **알림 받는다(선택)** — `"{이름} 포피스알림켜줘"` → `Poffice-Report-Bot`이 예약으로 마더 config를 직전과 diff → **개인 페르소나 말투**로 브리핑.

## 1. 심상윤 — Master PD (yellow_policy: auto, master)
- **행동**: 회사 마스터 미션(M0 홈페이지 런칭 등) 관리, 팀 전체 게이트 검수(🔴), WO(대표 지시) 발행.
- **동작**: 대시보드 최상단에 마스터보드 고정. 🔴 보고처리 컬럼에 검수 대기건 집계. WO는 각 팀원 상단 강제 고정.
- **효과**: 회사 전체 상태를 한 화면으로 파악. 검수 대기(🔴)·마감 임박 놓치지 않음. 브리핑은 **논리·정리형**(요점→근거→다음 액션).

## 2. 이정민 — Device (yellow_policy: report)
- **행동**: 현장 장치 트래킹/점검. 긴급 현장건 다수.
- **동작**: 옐로 게이트에 "팀장 판단 진행 · **팀원 보고 필수**" 라벨. 긴급건은 WO/중요=high로 상단.
- **효과**: 보고 누락 방지(report 정책). 긴급 현장 이슈가 대시보드 상단에 뜸. 브리핑은 **유아용 캐릭터 말투**(쉽게·다정하게).

## 3. 유지호 — Build (yellow_policy: auto)
- **행동**: 시공/자동화 파이프라인. 자재·공정 관리(추후 파트웍과 연계).
- **동작**: 옐로=자율 진행(보고 강제 없음). 미션 마일스톤으로 공정 진척 표시.
- **효과**: 자율성 유지하되 진행이 자동 기록·시각화. 브리핑은 **밝은 애니메이션풍 여성 캐릭터 말투**.

## 4. 오세원 — Art (yellow_policy: auto)
- **행동**: 파노라마 테마 포스터 등 아트워크. 진행률 중심.
- **동작**: 미션 마일스톤 트랙에 Day char가 progress만큼 전진(A1 60%). 로드맵 노드로 컷 단위 진척.
- **효과**: 진행 상태 한눈에. 브리핑은 **먼저 "큰일났다/별일없다" 결론 선언 후** 내용(빠른 판단).

## 5. 신승희 — Content (yellow_policy: report)
- **행동**: 테마 시나리오·퍼즐 집필. 방향 보고 잦음.
- **동작**: 옐로=보고 필수. WO(대표 지시 퍼즐 등) 상단 고정.
- **효과**: 보고 문화 정착 + 재미 요소로 동기부여. 브리핑은 **《스파이 패밀리》 아냐 말투**.

## 6. 기대 효과 (총평)
- **노션 수기 대체**: 대화가 곧 기록 → 온보딩·보고 자동화.
- **리스크 관리**: 권한 신호등(🔴 대표검수/🟡 보고/🟢 자율)로 승인 흐름 가시화.
- **동기부여**: 처리량·칭호·마일스톤(Day char) 게이미피케이션.
- **왜곡 방지**: 마더로그는 원문 참조·아카이빙, 텍스트 무결성 검증(원칙 2개).

## 7. 검수에이전트 테스트 플랜 (실제 동작 확인)
1. 대시보드가 `poffice_board.json` 로드 → **인물 선택 → 본인만** 표시(타인 격리) 확인.
2. 투두 체크 3상태 순환(todo→doing→done) + **내보내기** → `check_overrides`·`memo_overrides` 생성 확인.
3. 게이트 **권한 라벨**(🔴 대표검수/🟡 팀장판단·보고/🟢 자율) + `yellow_policy`(report/auto) 표시 확인.
4. 미션 **마일스톤**: progress→Day char 위치, roadmap 노드 done 표시 확인.
5. 세션로그 **나이별 opacity** + "더 보기" 확인.
6. WO(대표 지시) **상단 강제 고정** 확인.
7. `Poffice-MotherLog` 산출 config가 **스키마(A~H) 준수 + JSON 파싱 성공(원칙1) + 항목별 출처 근거(원칙2)** 확인.
8. `Poffice-Report-Bot`: 직전 config 대비 diff 항목만, 페르소나 말투로, **🔴·마감·리스크는 명확히** 브리핑되는지 확인.
