# 디자인 레퍼런스 — 글래스모피즘 (Arko Station 홈 UI)

## 0. 원본
- 출처: 게임 콘솔형 런처 홈 화면 "Arko Station 0.1 ALPHA" (가로 카드 캐러셀).
- 원본 파일: _(Drive 레퍼런스 폴더에 저장 후 파일명 기입)_

## 1. 첫인상 (한 줄)
**칠흑 배경 + 전기빛 파란 오로라(유체 광선) + 그 위에 뜬 프로스티드 글래스 카드들.** 카드는 반투명이라 뒤 오로라 색이 비쳐 카드마다 은은히 다른 색조를 띤다. 선택 카드만 흰 테두리로 또렷.

## 2. 레이어 구성 (뒤→앞)
1. **배경**: near-black(#04050a 정도) 위에 **일렉트릭 블루 오로라/유체 스트로크**(#1e3aff→#4d7bff, 가장자리 시안 하이라이트). 크게 굽이치는 리본 형태, 블러 처리된 볼류메트릭 광. 화면 우측이 더 밝고 좌측은 어둠.
2. **상단 상태바**: 풀폭 **알약(pill) 프로스티드 바**.
3. **카드 캐러셀**: 세로로 긴 라운드 카드 5장(가로 스크롤, 우측 카드는 화면 밖으로 잘림).
4. **하단 컨트롤 힌트**: `Ⓐ Select  Ⓑ Back`.

## 3. 글래스 카드 (핵심 레시피)
- 형태: **세로 긴 라운드 사각형**, radius ≈ 24–28px. 카드 간 간격 넓음.
- 표면: **반투명 프로스티드 글래스** — `backdrop-filter: blur(24–32px) saturate(1.15)`, 채움 `rgba(255,255,255,0.05–0.09)`.
- 테두리: **헤어라인** `1px solid rgba(255,255,255,0.14–0.20)` + 상단 안쪽 하이라이트(`inset 0 1px 0 rgba(255,255,255,.25)`).
- 그림자: 부드럽고 낮게 `0 20px 60px rgba(0,0,0,.45)`.
- **색 배어남**: 카드가 투명해 뒤 오로라가 비침 → 카드마다 색조가 다름(민트/보라/자주). 별도 배경색을 칠하는 게 아니라 **투명도로 뒷배경을 흡수**하는 게 포인트.
- **선택 상태(Settings 카드)**: 채움 약간 밝게 + **흰 2px 테두리**(`rgba(255,255,255,.9)`) + 미세 외곽 글로우. 라벨 밑에 짧은 언더바(_).

## 4. 앱 아이콘 (글로시 3D 그라디언트)
글래스 카드와 대비되는 **불투명 광택 3D 아이콘**(스퀴클 형태 또는 오브젝트):
- Arko Store: 민트→틸 그라디언트 서류가방.
- Settings: 핑크→오렌지 방사형 별(스타버스트), 중앙 발광.
- File manager: 보라→핑크 폴더 + 도형(△○).
- Internet browser: 라벤더 스퀴클 + 검은 물결 로고.
- Need for speed: 실제 게임 키아트(풀블리드 포스터형 카드).
> 아이콘은 **고채도 그라디언트 + 소프트 내부광 + 살짝의 하이라이트**. 카드(무채·투명)와 아이콘(유채·불투명)의 대비가 리듬을 만든다.

## 5. 상단 상태바
- **알약형 프로스티드 바**(카드와 같은 글래스), 좌우 풀폭.
- 좌: **큰 시각 `14:00`**(볼드) · 옆에 작게 `Tuesday · Jun 17` · **`Arko Station`**(볼드) `0.1 ALPHA`(디밍).
- 우: 상태 칩들 — 빨강 원형 `Ⓐ`(알림/계정) · **초록 토글 스위치** · **와이파이** 아이콘.

## 6. 타이포 / 컨트롤 힌트
- 카드 라벨: **볼드 화이트**(#f5f7fa), 카드 하단 중앙.
- 하단: `Ⓐ Select` / `Ⓑ Back` — 원형 버튼 글리프 + 라벨(게임패드 관례).

## 7. 팔레트 (근사 hex)
| 역할 | 값 |
|---|---|
| 배경 | `#04050a` (near-black) |
| 오로라 코어 | `#2b4cff` → `#4d7bff` |
| 오로라 하이라이트 | `#7aa8ff` / 시안 `#8fd8ff` |
| 글래스 채움 | `rgba(255,255,255,0.05~0.09)` |
| 글래스 테두리 | `rgba(255,255,255,0.14~0.20)` |
| 선택 테두리 | `rgba(255,255,255,0.9)` |
| 라벨 텍스트 | `#f5f7fa` / 서브 `rgba(255,255,255,.55)` |

## 8. 우리 프로젝트에 적용 포인트
- 핌허브의 기존 "리퀴드 글래스"(다크 뉴트럴 + `#00FF99` 절제)와 **결이 같음**. 단 여기선 **컬러 라이트(오로라)를 배경 주역**으로 써서 카드에 색을 입힘 → 허브에 쓰려면 `#00FF99` 계열 오로라로 치환 가능(액센트 과하지 않게).
- **핵심 차용거리**: ⑴ 투명도로 뒷배경 색을 흡수하는 카드(색을 칠하지 말 것) ⑵ 헤어라인+상단 인셋 하이라이트 ⑶ 선택=흰 테두리+글로우 ⑷ 무채 글래스 vs 유채 글로시 아이콘의 대비 리듬 ⑸ 알약형 상태바.
- 주의: blur 남용 시 성능·가독성 저하. 텍스트 뒤에는 충분한 대비 확보(오로라 위 흰 라벨은 미세 그림자/딤 레이어로 보정).
