# 코워크 핸드오프 — 포피스 "세션요약" 지침 (세션로그 기록 정본)

_목적: 팀원이 **"세션요약"** 이라고 말하면 코워크가 **이 문서만 보고** 개인 세션로그를 기록하도록._
_이 문서는 새 규칙을 만드는 게 아니라, 여러 곳에 흩어진 **이미 확정된 규칙을 한 곳에 취합**한 것이다._
_정본(내부 포맷의 최종 권한)은 각 스킬: `poffice-skill`(기록) · `poffice-motherlog`(집계). 상충 시 스킬이 우선._

---

## 0. 한 줄 요약
**"일한다 = 기록된다."** 대화가 서류가 된다. 팀원이 `"세션요약"`(또는 `"마무리"`)이라고 하면,
지금까지의 작업 대화를 **개인 세션로그 파일**로 저장한다. 서류를 새로 쓰는 게 아니라 대화를 그대로 남긴다.

## 1. 언제 (트리거)
- 팀원 발화: **`"세션요약"`**(작업 중간·끝), **`"마무리"`**(하루 끝: 마지막 정리 + 결과물 최종본 저장).
- **먼저 인사(`"나는 …팀원인 ㅇㅇㅇ이야"`)가 있어야** 누구의 로그인지 확정된다. 인사 없이 온 요약 요청은 이름을 먼저 확인.
- **30분 중복 방지**: 방금(≈30분 내) 기록했으면 또 안 남겨도 됨 — 알아서 넘어간다. `"세션요약"` 남발 불필요.
  _(근거: 대시보드 소통가이드 GUIDE.)_

## 2. 어디에 (저장 위치 · 파일명)
- **위치**: 블루필드 `[2.블루필드:아카이브].PIMM_archive` > **개인DB** > **{이름}** > **`Session_세션로그`**.
  - `Session_세션로그` **바로 아래 평면(flat) 구조**. 중첩 폴더·평행 구조 신설 금지.
  - 폴더 구조/Drive 경로·ID 정본 = **`pimm-artisan-session`** 스킬. Poffice는 그 구조를 그대로 소비.
  - board에 `member.session_dir`가 있으면 그 경로를 우선 사용(대시보드 결재 export의 `record_to`도 이 경로).
- **파일명**: **`{YYMMDD_HHMM}_{제목}_log.md`** (예: `260726_1530_포피스정합_log.md`).
  - 타임스탬프는 **`YYMMDD_HHMM` 분단위**(시간 포함) 규칙 엄수. 날짜만 금지.

## 3. 무엇을 (내용 규칙) — ★가장 중요
1. **원문 전문 보존 · 축약 금지.** 세션로그 본문은 실제 대화·작업 내용을 **그대로**. 요약·축약·재작성·의역·창작 금지.
   - 별도로 **1줄 헤드라인(`summary`)** 만 뽑는다. (요약본만 있으면 실제 업무 파악이 안 된다는 실사용 피드백.)
2. **분류 태깅** — 기록하면서 아래를 분류해 함께 남긴다(대시보드가 이걸로 렌더):
   - **게이트**: 🔴 레드(대표 검수 필요) / 🟡 옐로(팀장 판단, `report`면 보고 필수) / 🟢 그린(자율·기록만).
   - **체크(투두)**: `todo | doing | done` 상태. 대표/발신권자 지시는 **WO**(`wo:true`, 지시자 `issued_by`).
   - **미션**: 연결 미션 id·마일스톤 진척.
3. **무결성** — UTF-8·한글·이모지(🔴🟡🟢) 안 깨지게, JSON에 담을 땐 이스케이프 정확·개행 이스케이프. 저장 후 검증.
4. **무왜곡** — 과장·축소·창작 금지. 항목마다 출처(어느 대화/근거)를 남기고, **불확실하면 원문을 참조**한다.

## 4. 고칠 때 (정정) — 원본 불변
- 잘못 적혔어도 **지우지 않는다.** `"정정해줘"` → **고친 내용을 새 기록으로** 남긴다(원본은 그대로 보존).
- **하드삭제 금지**(폐기물 = 제로필드 이동). 중복 파일을 만들지 말고 같은 경로 제자리 수정(in-place)이 원칙.

## 5. 그다음 (집계 — MotherLog가 별도로 함, 참고용)
개인 세션로그가 쌓이면 **`poffice-motherlog`** 가 주기적으로(1일 1회 11:00 KST) 집계해
대시보드가 읽는 `poffice_board.json` 을 만든다. 세션요약 단계에서 이걸 직접 할 필요는 없지만, 기록 형식이 여기로 흘러가므로 참고:
- `sessions[]` 항목 = `{ ts:"YYMMDD_HHMM", file:"…_log.md", summary:"1줄", raw:"원문 전문" }`.
- **`raw`는 자르지 않는다.** 파일이 커지면 담는 **범위(윈도우)를 줄이지, raw를 자르지 않는다.**
- 윈도우 = 최근 **14일 + 인물별 최소 5건** + raw 예산 **200KB/인**. (주기 무관 — 하루 걸러도 다음 회차가 덮음.)
- 저장/미러 규칙은 `docs/handoff-poffice-js-mirror.md` 참조(런처 폴더에 `.json`+`.js` 미러, 제자리 덮어쓰기).
