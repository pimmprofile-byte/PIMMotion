# 플로직 교육 커리큘럼 설계 (핌허브 Plogic · 신입→마스터)

> 대상: **테마제작 아무것도 모르는 신입.** 목표: **플로직 마스터.**
> 형태: 데이(Day) 캐릭터 가이드 · 퍼즐/퀴즈로 재밌게 · 단일 HTML(핌허브 Plogic 탭).
> 원칙: "설명 → 바로 해보기(퍼즐) → 확인" 반복. 지루한 문서 아님, **게임처럼 진도가 쌓임.**

## 왜 이 순서인가 (Why→What→How→Master)
신입은 "왜 이렇게 하는지" 맥락 없이 절차만 주면 못 외운다. **철학·이유 먼저 → 용어 → 손에 익는 공정 → 크래프트 이론 → 실전 트랙 → 경영/판단(마스터)** 순으로, 매 단계 직전 것을 재료로 쓴다.

## 모듈 순서 (6단계 · 각 끝에 퍼즐 관문)
| # | 모듈 | 배우는 것 | 관문(퍼즐) |
|---|---|---|---|
| **0** | 오리엔테이션 — 우리는 왜 몰입을 짓나 | 이머시브란? PIMM이 만드는 것(방탈출·팝업·전시·공포). **PPP·IMM 철학**(Place·Play·Persona·Immersive). Day와 여정 시작 | 철학 4요소 매칭 |
| **1** | 지도 읽기 — 용어와 체급 | **Tier**(T1 프리미엄/T2 테마·스페이스/T3 베이직), **트랙**(PIMMscape 방탈출·PIMMex 공포·PIMM-UP 팝업), 핵심 용어사전 | 용어 카드 뒤집기·트랙 분류 |
| **2** | 아이디어 공정 — 테마제작의 심장 ★ | **Beat→Note→Render→Work→Max** 파이프라인. 각 단계 정의·하는 일·산출물·규칙 | **순서 맞추기 드래그** + 각 단계 산출물 매칭 |
| **3** | 크래프트 이론 — '겪게' 만드는 기술 | 서사구조 8-Cell · 게임퍼즐 **MDA** · **어포던스** · 장면연출 · 공간구성 · 제안서 쓰는 법 | 시나리오 판단 퀴즈(이 장면엔 뭘?) |
| **4** | 실전 트랙 — 골라 만들기 | PIMMscape(방탈출 테마) / PIMMex(공포) / PIMM-UP(팝업) 적용 차이 | 미니 케이스: 요구→트랙·Tier 선택 |
| **5** | 마스터 — 판단하는 사람 | 경영·판단로직(채산성·견적/운영/법무·IP/파트너십), 아티잔 마인드셋(5인 페르소나·MPA) | 종합 판단 시나리오(리스크·채산성) |

> 수료 시 **칭호: 신입 → 숙련 아티잔 → 플로직 마스터.** (포피스 게이미피케이션과 톤 일치)

## 형태 (어떻게 가르치나)
- **Day 캐릭터 내레이터**: 말풍선으로 개념을 친구처럼 설명(존댓+가벼움). 어려운 말은 풀어서. Day가 신입과 함께 성장하는 서사.
- **한 입 크기(chunking)**: 한 화면 = 한 개념. 스크롤 지옥 금지. 카드/아코디언.
- **설명→즉시 실습**: 개념마다 바로 미니 퍼즐. 맞히면 진도·별 획득, 틀리면 Day가 힌트.
- **퍼즐 유형**: ①순서 맞추기(파이프라인) ②용어 매칭/카드뒤집기 ③OX·객관식 ④시나리오 판단 ⑤빈칸 채우기.
- **진도 게이지 + 배지 + 칭호**: 상단에 진행도, 모듈 클리어 시 배지, 최종 칭호.
- **비주얼**: 밝고 게임 같은 UI(학습 피로 낮게) + PIMM 그린 포인트. 도식·다이어그램으로 개념 시각화(파이프라인·8-Cell·MDA).
- 단일 HTML, 로컬 진도 저장(localStorage), 외부 의존 0.

## 빠지지 않게 (커버 체크리스트)
철학(PPP·IMM) / Tier·트랙 / **Beat·Note·Render·Work·Max** / 서사구조·MDA·어포던스·장면연출·공간구성·제안서 / 트랙별 적용 / 경영·판단로직 / 페르소나·MPA / 핵심 용어사전.
→ 콘텐츠 추출 에이전트 결과로 각 항목 실내용을 채운다(원문 무왜곡).
