20종 해금 게임

룰렛으로 뽑고, 퍼즐을 풀고, 자물쇠를 열어 카드를 해금한다. 이 페이지는 배경 에셋·퍼즐 스키마·프롬프트를 한 곳에 모은 작업 문서다. 원본은 GitHub에 있다.

20칸 구조

현장 자물쇠함 그리드가 그대로 카드 분할이다. 가로 행 = 카테고리, 각 행 4칸. 오른쪽 두 칸(col3·col4)이 고난도라 카테고리마다 정확히 2개씩 배정된다.

테마 전체 3 이미지만 3 조작부 4 저난도 10 (미정)
진행 구조는 20문제가 동일하다. 퍼즐 풀이 → 코드(또는 열쇠) 획득 → 해당 자물쇠 개방 → 함 안 버튼 → 해금. 자물쇠가 카드마다 1개씩 20개이므로 조작부 문제도 자물쇠를 거친다. 조작부는 판정기가 아니라 코드를 얻는 수단이다.

자물쇠 배정 원칙

8종을 고난도 10문제에 전부 한 번씩 넣었다(열쇠·5자리 영문만 2회). 저난도는 반복돼도 무방하다 — 다양성은 고난도가 담당한다. 궁합이 특히 강한 셋:

  • 조이스틱 → 방향 자물쇠 (H05) — 방향으로 풀고 방향으로 잠근다. 설명이 필요 없다
  • 열쇠 자물쇠 → 테마 전체형 (H01·H06) — 열쇠는 코드가 없어 방에서 물리적으로 찾아오는 문제에만 쓸 수 있다. 사실상 강제 배정
  • 로딩바 토막 3개 → 3자리 숫자 (H08) — 토막 수와 자릿수가 일치
로딩바 주의. 토막 3개면 순열이 6가지뿐이라 찍기 확률 17%다. 순열 자체를 정답으로 쓰지 말고, 맞게 끼우면 3자리 코드가 드러나는 구조로 가야 한다. 6가지를 다 시도해도 어느 게 맞는지 알 수 없다는 게 핵심이다.

에셋 36개 — 계열 분류

파일명만으로는 계열이 안 갈린다. sub_bg_phase1과 sub_bg_phase2는 완전히 다른 기계고, sub_bg_roll*은 애초에 배경이 아니다. 구조가 다른 두 장을 스왑하면 화면이 튄다 — 같은 계열 안에서만 스왑하고, 계열이 바뀔 때는 디졸브 0.4s를 넣는다.

이름과 실제가 다른 것 둘

sub_bg_roll0~5는 배경이 아니라 룰렛 스핀 프레임이다. 6장 모두 같은 게임기 셸이고 좌측 5칸 LED 색 순서만 다르다. 원형 20슬롯 휠보다 낫다 — 1024폭에서 20슬롯은 카드 그림이 안 읽히고, LED 컬럼은 물리 게이밍보드 LED와 싱크시킬 수 있다.

f0(대기) → [스핀 IN] → f2~f5 루프, 감속 80→120→200→400ms
        → f1(전체 백색 = 확정 플래시) → 결과 팝업

sub_phase3~7은 성장 시리즈다. 좌측 X자 밸브, 우측 랙, 하단 팬·다이얼이 전부 같은 자리고 장식만 누적된다. 깨끗 → 녹·경고등 → 앰버 랜턴 → 크리스탈 → 나무 침식 → 마을 지배. 해금 진행도 n/20에 7 tier로 그대로 매핑되고, 전환은 해금 팝업이 떠 있는 동안 몰래 바꾸면 된다.
