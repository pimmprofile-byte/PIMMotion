# Part A — 빠른 시작 (워크플로우)

## A-0. 큰 그림 (3계층 + 순서)
- **시퀀스그룹 ▸ 시퀀스(게임 한 편, `SEQ#`) ▸ 씬(화면 단위) ▸ 박스(요소)**. 코드(`SEQ#`)는 자동·고정 키.
- **타임라인 = 진행 "순서"(시간 아님)**: 씬→인터랙션→씬 흐름.
- **자동저장이 곧 핸드오프**: 따로 내보내기 안 해도 코워크용 config가 자동 기록됨.

## A-1. 시작화면 (프로젝트 런처)
앱을 처음 열면 시작화면. 선택지:
- **＋ 새 프로젝트** — 위치(폴더) 설정하고 시작(빈 프로젝트).
- **간단 예제** — 배경 1 + 텍스트 1 불러오기(구조 체험용).
- **콤보(COM60) 예제** — 실제 콤보 시드 예제.
- **튜토리얼** — 단계별 사용법 가이드.
- **열기 / 폴더 열기** — 기존 프로젝트(.json/폴더) 불러오기. (폴더 열기는 Chrome/Edge 지원, 아니면 .json으로.)
- **이전 작업 복구** — 직전 자동저장 복구(“무시하고 계속” 가능).

## A-2. 처음부터 내보내기까지 (튜토리얼 8단계 = 툴 내 개념 카드)
1. **① 시퀀스(게임씬) 만들기** — 게임 한 편을 만든다.
2. **② 배경 이미지** — 1920×1080 풀캔버스 배경 올리기.
3. **③ 이미지박스 (+ 상태)** — 그림 한 장. 인스펙터 “+ 상태 추가”로 상태1~n 전환(가변) 이미지가 됨.
4. **④ 텍스트 (고정 / 가변)** — static(고정) / dynamic(조건→텍스트).
5. **⑤ 소리 (SFX / BGM)** — 효과음/배경음 에셋 등록.
6. **⑥ 타임라인 = 인터랙션 순서 (시간 아님!)** — 진행 지점(성공/실패 메모) 배치.
7. **⑦ 되돌리기 · 우클릭 메뉴** — Ctrl+Z, 우클릭 컨텍스트 메뉴 활용.
8. **⑧ 자동저장이 곧 핸드오프** — 내보내기 걱정 없이 작업. (고급 내보내기는 Part H.)

# Part B — 화면 구성

## B-1. 상단 탭 (뷰 3종 + 고급)
- **레이아웃(Layout)** — 1920×1080 캔버스에 박스 배치(디자인). 기본 작업 화면.
- **타임라인(Timeline)** — 진행 순서(인터랙션·씬 블록·영상·연속성 트랙). 유니티식 런 미리보기.
- **재생(▶)** — 전체화면 게임뷰. 레이아웃뷰=디자인 프리뷰(가변이미지 500ms 스프라이트), 타임라인뷰=유니티식 런. **ESC로 복귀**.
- **고급·핸드오프 단계** — 비트시트·에셋제작·에셋관리·이식·시뮬·빌드·완료. *초심자는 안 건드려도 됨.*

## B-2. 3분할 레이아웃 (좌·중·우 + 하단)
- **좌 패널 — 레이어/하이어라키**: 프리미어의 트랙 레이어 / Unity 하이어라키. 현재 씬 구성요소의 **z-순서(위=앞)** 계층. 접기 가능(중앙 넓게).
- **중앙 — 프로그램 모니터**: 프리미어 미리보기처럼 지금 편집 중인 씬의 **1920×1080 게임 화면**. 하단에 배율 표시(`1920×1080 · 1:1 Unity`).
- **우 패널 — 속성·이벤트(인스펙터)**: 선택 박스의 속성·상태·전환·이벤트 편집(Unity 인스펙터). 접기 가능.
- **하단 — 타임라인**: 인터랙션 순서·연속성 트랙. 열기/닫기.
- **콘솔(로그)**: 열기/닫기. **프로젝트 검증(무결성 체크)**. **툴 내 Claude 챗**(별도).

# Part C — 하이어라키 (시퀀스그룹 ▸ 시퀀스 ▸ 씬 ▸ 박스)

- **시퀀스그룹** — 코드 `그룹코드`(자동·고정). 더블클릭=이름변경, 드래그=순서변경 / 시퀀스를 여기로 드롭=이관. 삭제 시 소속 시퀀스는 첫 그룹으로 이관.
- **시퀀스** — 코드 `SEQ#`(자동·고정). 더블클릭=이름변경, 드래그=순서변경/그룹이동. 속성: phaseId·label·group·gameType(prefab)·mode(A/B)·timeLimit.
- **씬** — 더블클릭=이름변경, 드래그=순서변경. (박스를 씬으로 드롭 안 됨 — z-order는 씬 내에서만.) “이 씬 편집”으로 전환, 삭제 가능.
- **박스(요소)** — 더블클릭=이름변경, 드래그=z-order 재정렬(같은 씬 내, 위=앞). 잠금/가시성 토글.

# Part D — 박스(요소) 종류

툴바(레이아웃뷰 상단) / 우클릭 “＋ 박스 생성”에서 추가:
- **🌄 배경** — 1920×1080 풀캔버스 배경 에셋.
- **🖼 이미지박스 (Image / Button)** — 기본 그림 한 장. subtype=image/button.
- **🧩 가변이미지박스 (이미지 세트)** — 상태1~n을 전환하는 이미지박스(아래 Part G).
- **🅣 텍스트박스** — static(고정, Unity Text) / dynamic(가변, TextMesh). 폰트크기·정렬·글자색·배경색·테두리색. dynamic은 조건→텍스트 변형(variants).
- **✂️ 클리핑박스** — 겹치는 아래 콘텐츠를 이 모양/영역으로 자름(Part F).
- **프리팹 박스** — 공유 정의(Unity Prefab 개념)로부터 인스턴스 배치(Part G).

**공통 속성**: 좌표 `x/y/w/h`(1920×1080 기준·정수), opacity, 잠금(locked), 가시성(hidden), role, 연속성(continuity), span(인터랙션 구간).

# Part E — 프레임 모드 (크롭 / 풀 / 그래픽) ★좌표 핵심

이미지가 박스에 **어떻게 맞춰지는지**를 정하는 3모드. 좌표 어긋남의 대부분이 여기서 옴. (정본: `docs/handoff-pimm-unity-frametype.md`.)
- **크롭프레임(cropframe·기본)** — `object-fit: cover`. 이미지가 박스 W×H를 꽉 채우고 넘침 중앙 크롭. (버튼은 contain.) 특정 부분만 원하면 자르기(crop) 지정.
- **풀프레임(fullframe)** — 이미지=1920×1080 전체, 위치가 이미지에 구워짐. 박스=콘텐츠영역 표시.
- **프레임그래픽(framegraphic)** — 박스=이미지 원본 크기(비율락)로 재생성 → fill이어도 왜곡 0. “에셋저장소 이미지를 프레임그래픽으로 적용” 시 박스가 이미지 원본 크기로 재생성됨.
> **비율 락** — 리사이즈 시 이미지 원본 비율 유지(잠금) / 해제 시 자유 변형.

# Part F — 자르기(크롭) · 클리핑(마스크 / 클리핑박스)

## F-1. 자르기(크롭) — 비파괴 트림
- 대상: **이미지가 있는 박스**(우클릭 ✂️ 자르기, 또는 인스펙터). “이미지가 있는 박스만 자를 수 있습니다.”
- 흐름: **자르기 모드 → 핸들 드래그로 영역 지정 → ✓ 적용**(비파괴, 언제든 재조정). 자르기 해제=원본 복원.
- **투명 여백 자동 트림** 옵션. “이 영역만 남기기(비파괴).”

## F-2. 클리핑박스 (쉬움·권장)
- **✂️ 클리핑박스 추가** — 박스 하나만 만들면 끝. 이 박스와 겹치는 **아래 콘텐츠**를 그 모양/영역으로 자름. 빈영역/박스 위 어디서나 추가 가능.
- 도형: 사각/둥근(radius)/타원. Unity 매핑: 사각·둥근=RectMask2D, 타원=SpriteMask(알파).

## F-3. 클리핑마스크 (고급·일러스트식)
- **마스크 박스(위) + 콘텐츠 박스(아래) 2개 선택** 후 생성. “보통은 ✂️ 클리핑박스가 더 쉬움.”
- 마스크 해제 가능. (마스크박스는 렌더 숨김, role:mask.)

# Part G — 상태(배리에이션) · 프리팹

## G-1. 상태(배리에이션) = 🎭 이미지 교체 슬롯
- 한 이미지박스가 가질 수 있는 **여러 이미지(상태1~n)**. 인스펙터 “+ 상태 추가”(이미지박스를 먼저 선택). 기본 상태 지정, “지금 표시할 상태” 선택.
- 재생/타임라인에서 `setState`로 스프라이트 스왑(코드 아님). 상태 전환: `상태명 → 상태명`.

## G-2. 프리팹 (🧩 공유 정의)
- Unity Prefab과 1:1. 시퀀스 공유 정의로부터 인스턴스 배치(instanceIndex). 인스턴스별 표시 상태 선택 가능.

# Part I — 연속성(continuity) · 타임라인

## I-1. 연속성
- `persist`(여러 씬에 걸쳐 **유지** — 오브젝트 재사용, 파괴/재생성·디졸브 없음, 공유 crossSceneId) / `change` / `enter` / `exit`.
- 하이어라키/타임라인에서 “**옆 씬 블록까지 연장**(연속성)” → 하이어라키 자동복사 + persist. `⇥`=옆 씬까지 연장. 연장 축소(원상) 가능.

## I-2. 타임라인 뷰 (진행 순서)
- **블록**: `scene`(씬 통째) / `interaction`(진행 지점, 성공·실패 메모) / `video`(영상 구간). 순서대로 진행.
- **씬 블록 배치**: 더블클릭 또는 Repo에서 트랙으로 드래그. 블록 클릭=선택/속성창, 드래그=순서변경, 제거 가능.
- **인터랙션**: 씬 사이 진행 지점(성공/실패 메모), 추가 가능. 클릭=편집+플레이헤드. action(전환 종류·메모).
- **연속성 트랙**: 박스가 걸치는 인터랙션 구간(가장자리 드래그=구간 조정). persist 걸침 블록 수 표시.
- **플레이헤드**: 스윕 재생(블록 순서 전체화면 게임뷰, ESC 복귀). 해제=전체 보기.
- **트랙 높이 조절**: 경계 드래그(더블클릭=기본), 모든 트랙 펼치기/접기(클립 많아 라벨 안 보일 때).
- **타임라인 비우기**. (비어 있으면 “Repo에서 씬박스를 올리세요.”)

# Part J — 씬 스크립트 / 시퀀스 스크립트 (ver1.15·1.17)

- **📝 씬 스크립트** 버튼(레이아웃 툴바) — 지금 편집 중인 **씬 전반** 설명·이벤트·흐름. 씬 인스펙터 ‘씬 스크립트’와 같은 내용(`sceneNote` · `scenes[].sceneNote`로 export).
- **📜 시퀀스 스크립트** 버튼(그 옆, ver1.17) — 지금 **시퀀스(게임 한 편) 전반**의 기획·흐름·규칙. 시퀀스 인스펙터 ‘시퀀스 스크립트’와 같은 내용(`seqNote` · export **최상위** `seqNote`).
- 둘 다 모달 또는 인스펙터에서 편집·실시간 저장. **코워크가 빌드 시 읽음**(시퀀스 스크립트=게임 전체 맥락, 씬 스크립트=씬별 맥락).

# Part K — 에셋 (스토어 · 에디터 · 레퍼런스 · 오디오)

- **에셋저장소(assetsEdited)** — 에셋에디터 저장본. “프레임그래픽으로 적용” 시 박스가 이미지 원본 크기로 재생성.
- **에셋에디터** — 이미지 편집(다른 이미지를 레이어로 위에 합치기 등). 저장 시 assetsEdited.
- **템플릿 라이브러리** — 박스 묶음 템플릿. (“삽입할 템플릿이 없습니다 — 에셋저장소에서 먼저 만드세요.”)
- **🖼 레퍼런스 이미지 라이브러리** — 폴더/파일에서 참고 이미지를 모아 이미지 생성 프롬프트에 첨부. 전체 비우기 가능.
- **오디오** — **+ SFX**(효과음 등록) / **+ BGM**(배경음, 시퀀스 전 구간 루프/유지).
- **인게임 에셋(assetsIngame)** — 최종 씬에 실제 올라간 것만(dedup). 빌드용 정제본.

# Part L — 정렬 · 배치 · 줌 · 그리드 · 스마트가이드

# Part Q — 내보내는 데이터 (핸드오프 JSON) + 코워크 빌드 노트

> 위 기능들이 **JSON으로 어떻게 나가는지**. 코워크는 이걸 읽어 유니티(핌플레이어)로 결정론적 빌드. (정본: `buildLayoutJSON`/`encodeHandoffBox`, 좌표/프레임 상세 `docs/handoff-pimm-unity-frametype.md`.)

## Q-1. 코워크에게 넘어오는 3가지(+선택)
1. **인게임 에셋 정제본** = `assets/assetsIngame/` — 최종 씬에 실제 올라간 이미지/오디오만(dedup).
2. **에셋 활용방식**(슬림 config) = 각 에셋을 어디에·얼마 크기로·어떻게: 좌표(unity 앵커)·크기·frameType·클립·크롭·z순서·연속성.
3. **게임 진행방식**(config) = 타임라인 블록(씬/인터랙션/영상) 순서·박스 이벤트·성공/실패 메모·전환.
- (선택) `encode/<SEQ#>.pimmgame.json` = 위를 임베드한 자체완결 번들(에셋 data URI 포함).

## Q-2. 레이아웃 JSON 스키마 (요지)
최상위: `sequenceId, phaseId, seqLabel, seqNote(시퀀스 전체 스크립트·ver1.17), resolution:[1920,1080], background, bgm, prefabs[], activeSceneId, scenes[]{sceneId,name,order,sceneNote,boxes[]}, interactions[]{id,label,note,action}, boxes[](활성씬·하위호환)`.

박스 1개(`encodeHandoffBox`):
- `index,id,type,x,y,w,h`(정수·1920×1080), `opacity,locked,hidden`, **`unity`**(anchorMin/Max — **Y-flip 완료**, 그대로 사용), `role`
- 이미지/버튼: `subtype, assetId, fps, states[]{id,name,assetId,hasImage}, defaultStateId, activeStateId, hasImage`
- 텍스트: `textMode(static/dynamic), text, fontSize, fontColor, align, bgColor, borderColor, variants[]{condition,text}`
- 프리팹: `kind:"prefab", prefabId, instanceIndex, subtype, assetId, stateId`
- 공통: `span{fromInteraction,toInteraction}, continuity(persist/change/enter/exit), crossSceneId`
- **`clip`**(+`unityMask`: RectMask2D/SpriteMask) · **`crop`{x,y,w,h}**(0..1 정규화, +`cropUnity`{mode:"spriteRect"})
- **`frameType`**(cropframe/fullframe/framegraphic) + **`frameTypeUnity`**(fit 힌트) + framegraphic이면 `ratioLock, frameSrcW, frameSrcH`
- `prompts[]` · `events[]{id,name,trigger,commands[]{id,type,params}}`
- 마스크박스면: `maskRole:"mask", maskFor[], renderHidden:true, maskShape` (클리핑박스는 `role:"clip", clipBox, clipRadius, unityMask`)

## Q-3. 코워크 빌드 노트 (결정론 · 스킬 §6 요약)
1. **스터디 게이트** — 바로 만들지 말 것. `resolution`·박스별 `frameType/crop/clip/unity`·**모든 sceneNote(=씬 스크립트)·박스 메모·prompts·인터랙션 메모** 완독 → 적용순서 제시·확인 후 빌드.
2. **frameType fit 준수** — cropframe=object-fit:cover(중앙크롭, `preserveAspect` 금지·공용 CoverSprite 헬퍼) / framegraphic=fill(왜곡0) / fullframe=fullscreen. (상세·C# 헬퍼: `docs/handoff-pimm-unity-frametype.md`.)
3. **좌표** — `unity.anchorMin/Max` Y-flip 완료, 그대로. 픽셀은 1920×1080.
4. **리스킨 우선** — 진행방식이 기존 메커니즘으로 표현되면 config+에셋 교체만(C# 0줄). 새 메커니즘만 명시적 플래그 후 추가.
5. **상태(배리에이션)=스프라이트 스왑**, **연속성 persist=오브젝트 재사용(디졸브 없음)**, **이벤트=trigger+commands 지시문→구현**.
6. **텍스트 폰트만 브라우저↔Unity 미세차** — 위치·크기는 맞음, 최종 Play로 QC.

# 부록 — 문제해결 (자주 나오는 토스트)

- “이미지가 있는 박스만 자를 수 있습니다” / “자를 이미지 박스 1개를 선택하세요” → 크롭은 이미지 박스만·1개 선택.
- “마스크 박스(위)와 콘텐츠 박스(아래)를 함께 선택하세요” → 클리핑마스크는 2개 선택.
- “상태 추가: 이미지박스를 먼저 선택하세요” → 상태(배리에이션)는 이미지박스 선택 후.
- “삽입할 템플릿이 없습니다 — 에셋저장소에서 먼저 만드세요.”
- “씬이 없습니다 — 먼저 씬을 추가하세요.”
- “타임라인이 비어 있습니다 — Repo에서 씬박스를 올리세요.”
- “폴더 열기는 Chrome/Edge에서 지원됩니다 — 파일(.json)로 엽니다.”
- “이전 작업을 복구했습니다” / “프로젝트 검증(무결성 체크)”로 상태 확인.

> ※ 좌표·에셋 크기 문제(“좌표가 다르다/눌린다”)는 대부분 **프레임 모드 선택**(Part E) 문제입니다. 박스에 채우려면 cropframe, 이미지 원본크기 유지하려면 framegraphic, 배경이면 fullframe. 상세: `docs/handoff-pimm-unity-frametype.md`.
